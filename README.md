# 磐基 Keystone · 合规留痕中台

> 面向法规强制型场景（特种设备、食安、危废、排污许可、消防、职业健康）的**合规留痕中台**。
> 把散落的法条，变成每天可执行、可取证、可追溯的任务与台账。

**本仓库是产品文档与更新日志仓库，不包含源代码。** 系统为商业软件，按授权方式交付（私有化部署 / 源码授权 / 白标）。

---

## 它解决什么问题

法规要求"日管控、周排查、月调度"，要求"无纸化维保""五即管理"，要求检查时**拿得出来**。
但实际情况通常是：

| 现实 | 后果 |
| --- | --- |
| 台账写在纸上、照片存在个人手机里 | 检查当天翻不出来 |
| 记录可以事后补、可以改 | 一旦被质疑真实性，无法自证 |
| 整改靠口头催 | 隐患不闭环，复查没依据 |
| 每个行业一套系统 | 换一个行业，重做一遍 |

磐基的做法是把**证据链**做成底座，行业差异只做模板：

```
法规条款 → 可执行义务 → 定时任务 → 现场取证（照片/签名/GPS/时间戳）
        → 只追加台账（哈希链）→ 每日存证锚 → 检查时一键导出履职档案
```

## 核心能力

- **义务登记与版本化**：法条变了，模板跟着版本走；历史记录按当时版本可复现，经得起"翻旧账"
- **任务与打卡**：按班次、按设备、按主体自动生成，逾期预警
- **现场取证**：拍照、电子签名、GPS、时间戳四要素绑定，防代填
- **不可篡改台账**：只追加 + 哈希链，改动留痕
- **整改闭环**：发现 → 整改 → 复查 → 销号，全程留证
- **监管报送**：适配器式对接上级平台，附报文留痕与重放
- **履职档案导出**：一次检查要的材料，一键成册，页脚带防伪溯源码
